最近の気づき: コードテストは、数学のテストを人間が解くのとはわけが違う<br>
人間はテストを解く時効率的な方法を求めたくなるし、教育の場でもそう教わってきたが、<br>
「コンピュータに解かせる」という前提に立つと、「複雑な思考の末に簡単な計算で解ける」より「計算自体はシンプルだけど計算数がものすごく多い」方が実装しやすい。<br>
ラケットを持つことで身体機能が拡張されるスポーツがあるように、コンピュータに実行させることで計算能力と処理速度の大幅拡張を得られる、というのがITを使う意味なのだなあと感じたし、<br>
その能力をより引き出すために、プログラマはある意味自分が人間であることを一旦忘れないといけないのかもしれない。<br>

2026/2/26<br>
最近の気づき： whileの後はループが続く条件、ifの後はループを止める条件を記述するべし<br>
ifの条件「a or b がFalseなら繰り返しを止める」と、
whileの条件「a and b がTrueの間だけ繰り返しを続ける」は等しい。<br>
条件文ではandとorがどうはたらくのか、意味を考えることが重要。<br>
